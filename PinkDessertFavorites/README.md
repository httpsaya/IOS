# Pink Dessert Favorites 🍓

A pastel-pink UIKit Favorites List app built for the **UITableView & Custom Cells** lab.

## Features
- 20 unique dessert entries and 20 original vector-style PNG illustrations in `Assets.xcassets`.
- Custom prototype `FavoriteCell` in `Main.storyboard`, with 5 pink SF Symbol hearts.
- Images, multiline titles and subtitles; reusable cells through `UITableViewDataSource`.
- No frames, anchors, or constraints created in Swift.
- iOS 15+; one iPhone screen; Xcode project contains `AppIcon`.

## Run
1. Open `PinkDessertFavorites.xcodeproj` in Xcode.
2. Choose `PinkDessertFavorites` target and an iPhone simulator.
3. Press Cmd+R.
